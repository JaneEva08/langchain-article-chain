## Домашнее задание

**Задача:** создай собственную цепочку из 3–4 звеньев (этапов) для решения конкретной задачи — например, генерации статьи, кода, анализа данных или подготовки отчёта.

Опиши логику шагов и реализуй цепочку в коде на Python с помощью LangChain (или в любом другом инструменте; если ты не программист — можно оформить как псевдокод с пояснениями).

**Минимальная структура цепочки:**
1. Анализ задачи
2. Подбор инструментов
3. Реализация (генерация результата)
4. Проверка / ревью

**Формат сдачи:**
- ссылка на GitHub-репозиторий, или
- zip-архив с кодом, или
- скриншоты работы цепочки

(Награда за выполнение — 20 монет. Уровней базовый/средний нет.)
