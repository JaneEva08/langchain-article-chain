# Цепочка запросов (Chains): статья из одной темы

Домашнее задание VPf05 курса «Профессия вайб-кодер» (Zerocoder), модуль 7.
Цепочка из 4 звеньев на LangChain: по теме получается готовая статья в Markdown.

```
тема → 1. analysis → 2. outline → 3. draft → 4. review → output/<тема>.md
```

| # | Звено | Вход | Выход |
|---|---|---|---|
| 1 | `analysis_chain` — анализ задания | тема | JSON: цель, аудитория, ключевые вопросы, тон |
| 2 | `outline_chain` — структура статьи | JSON анализа | JSON: заголовок, разделы с тезисами, вывод |
| 3 | `draft_chain` — реализация | анализ + структура | статья в Markdown |
| 4 | `review_chain` — проверка / ревью | замечания + статья | исправленная статья |

Каждое звено получает только нужные ему данные. Ревью двухуровневое: сначала бесплатная
локальная проверка (`minimal_review`: есть ли H1, все ли разделы плана, достаточный ли объём),
и только при замечаниях вызывается `review_chain` (запрос к модели). Исправление принимается,
если замечаний стало меньше.

## Запуск (Windows, PowerShell)

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
copy .env.example .env      # впишите OPENAI_API_KEY
python article_chain.py "Как начать работать с Docker"
```

macOS / Linux: `source venv/bin/activate` и `cp .env.example .env`.

В `output/` появятся `<тема>.md` (статья) и `<тема>.steps.json` (результаты звеньев: анализ, план,
найденные замечания). Тема может быть на русском — статья пишется на языке темы, файл
получает транслитерированное имя и не затирает прошлые запуски.

Настройки в `.env`: `OPENAI_API_KEY`, `OPENAI_BASE_URL` (любой OpenAI-совместимый сервис),
`AI_MODEL`, `TEMPERATURE`, `LOG_LEVEL`.

## Тесты

```powershell
python -m pytest -q
```

Тесты подменяют модель заглушкой: ключ и сеть не нужны.

> API-ключ хранится только в `.env` (он в `.gitignore`). Не вставляйте ключ в код и не коммитьте его.
